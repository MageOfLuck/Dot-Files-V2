# Edge Control — UI and notification update (2026-10-22)

## Behavior fixes

- Clicking a notification popup invokes its desktop-notification **default action**, just as clicking an actionable card in the notification menu does.
- If the app did not provide a default action, the popup instead opens the Notifications menu. This avoids accidentally triggering unrelated actions such as Archive or Snooze.
- Dismiss/× is now a separate explicit action, and hiding a toast is not treated as dismissing a notification.
- Notification popups pause their countdown while hovered, and closing a notification also removes a stale toast.
- Removed a redundant `toastVisible` toggle that could desynchronize popup state from notification history.
- Quickshell's own notification actions are invoked through the same hub helper for popup and menu interactions.

## Interface changes

- Added reusable `MenuCard.qml` and `SectionHeading.qml` components for uniform sections, inset spacing, rounded surfaces, borders, and labels.
- Cleaned up audio, Bluetooth, Wi-Fi, notification, clock, media, and system menus.
- Centered arrow indicators inside dropdown selectors with vector chevrons, and made button text and close controls consistently centered.
- Improved empty results, search filtering, connected/saved device statuses, and popup information hierarchy.
- Top-bar buttons now show an active menu state.
- Media controls now have a seek bar with elapsed and total time for players supporting seeking and track length, plus fallback when a player vanishes.
- Dashboard stats refresh without assigning over a `running` property binding.
- Added `Settings.sectionSurface`, `Settings.hoverSurface`, `Settings.borderColor`, and `Settings.notificationHistoryLimit`.
- Popup display duration now defaults to 5 seconds; set `notificationDuration` and `notificationMaxVisible` in `Settings.qml` to customize.

## Installation

From a terminal, extract this ZIP somewhere outside your installed Quickshell directory and run:

```bash
unzip -q quickshell-polished.zip
bash quickshell/install.sh --update
```

The installer automatically backs up `~/.config/quickshell/edge-control` (or the corresponding `$XDG_CONFIG_HOME` path) before replacing files. It keeps your configuration path and existing Hyprland keybindings.

Test popup behavior with a notification that has a **default action**, such as one generated by an application or a browser. A basic `notify-send` with no default action is expected to open the notification menu instead of launching an application. Close the menu with Escape or ×.
